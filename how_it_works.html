Claude Code logs ~/.claude/projects/
*.jsonl One record per API call, with its token counts. Read only.
extract_usage.py Copies the token counts of every call into one table.
data/ usage.csv
one row per call
prompts.json
turns.json Git-ignored: it holds your prompt text.
prices.py  tokens × list price = US$
analyze_usage.py Where the spend went. With --split, cost per call before and after a date.
simulate.py Replays the same calls as if long sessions had restarted at a size cap.
audit_startup.py Sizes each part of a new session's first prompt. Reads the logs directly.
